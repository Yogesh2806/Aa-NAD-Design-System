Get started

No build step needed

Load the tokens, the stylesheet, React 18 and the bundle. Components are on window.AaNAD. Switch themes with data-theme on <html>, or follow the OS with AaNAD.watchSystemTheme().

<link rel="stylesheet" href="tokens/tokens.css">
<link rel="stylesheet" href="dist/aa-nad.css">
<script src="https://cdn.jsdelivr.net/npm/react@18/umd/react.production.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/react-dom@18/umd/react-dom.production.min.js"></script>
<script src="dist/aa-nad.js"></script>

const { Button } = AaNAD;
ReactDOM.createRoot(app).render(React.createElement(Button, { variant: 'primary' }, 'Continue'));
