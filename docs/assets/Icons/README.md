Ionicons 8.1.0 (MIT): the 46 most-used glyphs, each as `<name>-outline.svg` (rest state) and `<name>-filled.svg` (selected or active), on a 512 viewBox. The ink is baked in as NAD Ink `#111111` so the files work in `<img>`; in code use the `Icon` component, which inherits `currentColor` and includes all 515 Ionicons. Name icons by Ionicons name (`notifications`, `chevron-forward`). Reserved meanings: `close` dismisses, `trash` deletes permanently, `chevron-forward` navigates deeper, `ellipsis-horizontal` opens more actions.
