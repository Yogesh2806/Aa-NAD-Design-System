Line-art scenes in the Aa NAD illustration style: ink `#111111` outlines about 3px wide, white fills, grey `#a3a3a3` and `#efefef` accents, a ground line and grey leaf clusters, with no accent colour. The canvas is 400×300 with a transparent background. Use them through `EmptyState`; in the dark theme the component inverts them.
