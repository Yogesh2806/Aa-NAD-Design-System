# TextArea

Multi-line text input; shows a live character count when `maxLength` is set.

**Use when** messages, descriptions, feedback.

**Don't** use for single-line values.

**You provide** `label`, `rows` (default 4), `maxLength`, `helperText`, `error`, plus native textarea props.

**Accessibility** Same rules as TextField; the counter is a polite live region.
